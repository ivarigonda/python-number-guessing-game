# Number Guessing Game (Python)

A simple console-based number guessing game written in Python.

The computer randomly chooses a number between **1 and 50** and the player keeps guessing until they find the correct number. 
After each guess, the program tells the player whether their guess is **too high** or **too low**.


## How to Run

1. Make sure you have **Python 3** installed.
2. Download or clone this repository.
3. Open a terminal / command prompt in the project folder.
4. Run:

```bash
python main.py
